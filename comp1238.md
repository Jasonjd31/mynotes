## Week 1 - History
Cuneiform writing was developed in Mesopotamia using a wedge-shaped stylus on clay.
The Epic of Gilgamesh is one of the earliest known works of literature.

## Week 2 - Bits and Bytes
A bit represents a binary state (0 or 1), and 8 bits make up a byte.
RAM is fast volatile memory, while SSDs and HDDs provide non-volatile long-term storage.

## Week 3 - Structure of Text
Markdown and HTML use markup to add structure and formatting to text.
JSON and XML are popular text formats used to store and transmit structured data.

## Week 4 - Manipulating Text & Text Editors
Text editors handle plain text files directly without hidden formatting, unlike word processors.
Touch typing helps you code and write faster by building muscle memory.

## Week 5 - Manipulating Text & Text Editors
The command line lets you interact with the computer by typing text commands.
Piping (|) allows you to chain small command-line tools together to perform tasks efficiently.
